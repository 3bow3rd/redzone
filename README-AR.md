# Red Zone Club — تطبيق أندرويد أصلي (Kotlin + Jetpack Compose)

أُعيد بناء التطبيق بالكامل كتطبيق أندرويد أصلي. لا يوجد WebView ولا HTML ولا Capacitor.
كل المنطق (الحساب، المؤقتات، الفواتير، السجل، المزامنة، القفل) أُعيدت كتابته بـ Kotlin بنفس المعادلات.

## البناء بدون تثبيت أي برنامج (GitHub Actions)
1. أنشئ مستودعاً Private على github.com وارفع **كل** محتويات هذا المجلد (بما فيه `.github`).
2. تبويب **Actions** ← **Build Native Android App** ← **Run workflow** (5–10 دقائق).
3. من **Artifacts** حمّل `RedZoneClub-APK`، فك الضغط وثبّت `app-debug.apk`.

## البناء من Android Studio
افتح المجلد في Android Studio (Koala أو أحدث) ثم Run. المتطلبات: JDK 17، SDK 34.

## ما الذي تغيّر
| الميزة | قبل (ويب داخل APK) | الآن (أصلي) |
|---|---|---|
| الواجهة | HTML/JS | Jetpack Compose (RTL عربي) |
| التخزين | localStorage | SharedPreferences |
| المنبه | إشعارات Capacitor | AlarmManager + قنوات إشعار بنغمات مخصصة |
| البصمة | إضافة Java | androidx.biometric |
| المزامنة | fetch + EventSource | Firebase Realtime Database (REST + SSE) بنفس بنية البيانات |

المزامنة **متوافقة مع بياناتك الحالية**: نفس المسارات (`lounge/state` و`logs/*`) ونفس صيغة الحقول، فيمكنك ربط التطبيق الجديد بنفس قاعدة Firebase ويقرأ الجلسات والسجل القديم.

## ربط المزامنة
الإعدادات ← «ربط / إعدادات المزامنة» ← الصق رابط Realtime Database وكلمة السر (Database secret) ← «ربط واختبار الاتصال».
المؤشر في أعلى الشاشة: أخضر = متصل، أحمر = محلي/بلا إنترنت. تغييرات السجل أثناء انقطاع الإنترنت تُرفع تلقائياً عند عودته.

## ملاحظات
- أول تشغيل: اسمح بالإشعارات. لإشعار منبثق موثوق اجعل البطارية «بلا قيود» للتطبيق.
- المنبّه يُعاد جدولته تلقائياً بعد إعادة تشغيل الهاتف.
- إضافة نغمة من ملف تتطلب أندرويد 10+.
- تثبيت هذا الـ APK فوق القديم قد يتطلب حذف القديم أولاً (توقيع مختلف).
- نسخة ويندوز (EXE) غير مشمولة هنا؛ هذا المشروع أندرويد فقط.

## ما الجديد في الإصدار 3.0
- **حذف السجل محمي:** حذف أي عملية من السجل يطلب نفس الرمز السري أو البصمة التي تقفل الإعدادات (إن كان القفل مفعّلاً).
- **إنذار للجهاز الآخر:** عند إدخال رمز خاطئ (للإعدادات أو للحذف) أو طلب تغيير/استرجاع الرمز أو تغييره أو إيقاف القفل، يصل إنذار (إشعار + نافذة + صوت) للجهاز الآخر. **يتطلب ربط المزامنة على الجهازين**، ويصل ما دام التطبيق يعمل على الجهاز الآخر (أو عند فتحه).
- **السجل الكامل:** أُضيف إليه زر «➕ جلسة قديمة» وزر «📊 تصدير السجل (Excel)» (أوراق: السجل، ملخص الأيام، المشروبات). أُزيلت «جلسة قديمة» من الشريط السفلي.
- **تصدير الفاتورة Excel:** من نافذة أي فاتورة (في السجل أو عند إنهاء الجلسة).
- **الجلسة القديمة:** تُدخل وقت البدء فقط + المبلغ، فيُحسب وقت الانتهاء تلقائياً من سعر الساعة (أو اختر «حسب وقت الانتهاء» فيُحسب المبلغ). والمشروبات تُضاف بالضغط على أصنافها بدل كتابة مبلغ.
- **البيع المباشر** صار في الشريط السفلي.
- **المنبه:** زر «خيارات المنبه» يفتح نافذة منبثقة للتعديل.
- **المشروبات:** 4 أيقونات في كل صف، وإيموجي تلقائي حسب الاسم (نودلز 🍜، شاي 🍵، نسكافيه/قهوة ☕، عصير 🧃، مياه 💧 ...). الأسماء غير المعروفة تأخذ 🍽️.
- **الحساب:** مبلغ الوقت يُقرَّب دائماً للأعلى إلى مضاعفات **500** ل.س (الحد الأدنى 500). مثلاً 11300 ← 11500 و5600 ← 6000. (التغيير من الثابت `Step`/`STEP` في Models).
- **الاسم والتصميم:** RED ZONE CLUB بحروف كبيرة متوهجة وكلمة CLUB أصغر، وتصميم عصري بألوان الشعار.
